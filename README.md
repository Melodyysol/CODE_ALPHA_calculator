# Modern Calculator

A clean, responsive calculator app built with plain HTML, CSS, and JavaScript.

## Features

- Basic arithmetic operations: addition, subtraction, multiplication, and division
- Decimal input support
- Delete key and reset functionality
- Last answer recall with ANS
- Keyboard support for digits, operators, Enter, Escape, and Backspace
- Responsive layout for desktop and mobile screens
- Error-safe behavior without crashing the app

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Project Structure

- index.html — UI structure and calculator shell
- index.css — styling and responsive design
- index.js — calculator logic and interaction handling

## How to Run

1. Open the project folder in your browser.
2. Launch the app by opening index.html directly, or serve it locally with a small static server.
3. For example:

   python3 -m http.server 8000

4. Then visit http://localhost:8000 in your browser.

## Notes

This calculator is intentionally lightweight and dependency-free so it can run in any modern browser without needing a build step.
